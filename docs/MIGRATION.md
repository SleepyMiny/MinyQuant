# MinyAI에서 MinyQuant로 이전한 기록

2026-11-10 비공개 MinyAI의 주식 설계에서 분리했다. 원본 커밋과 내부 파일 식별자는 비공개 인계 기록에서 관리한다. 실행 계약·작업·시험은 이 저장소에 모두 포함한다.

| 원본 | MinyQuant 정본 | 처리 |
|---|---|---|
| 금융 실행 계약 6.1~6.3 | [design.md](design.md) | 본문 그대로 보존 |
| T06/T09 | [작업 카드](implementation/TASKS.md) | ID 보존, 패키지 경로를 src/minyquant로 확정, 독립 시작 작업 Q00 추가 |
| A33~A41/A44 | [수용시험](validation/ACCEPTANCE.md) | ID·시험·기대 결과 보존, 과거 T01/T04 소유권을 T06으로 매핑 |
| 공통 연결 경계 | [MinyAI 연결](integration/minyai.md) | 코어 계약을 참조하고 서비스 책임 명시 |
| 금융 운영 조건 | [운영 준비](operations/RUNBOOK.md) | 서비스 내부 복원·대사 책임과 공용 장비 조정 구분 |

이전 대상은 설계 문서다. 이전할 주식 런타임 코드·실제 데이터·계좌·키는 없었다. MinyAI의 스타터·코어 코드·과거 전체 저장소 이력은 가져오지 않는다. 상세 금융 문서는 앞으로 이 저장소에서 갱신하며 MinyAI에는 정본 링크와 이전 기록만 둔다.
