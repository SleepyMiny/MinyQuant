## 목업 사용 흐름 검토 (Q-M00)

상태: **NOT RUN**. 합성 데이터의 정상 흐름과 만료/GPU 불가/UNKNOWN/미확인 비용 화면을 클릭으로 전환하고, 사용자 검토 의견·반영/보류 사항을 기록한다. 모의/실거래 비활성·AI 제안/실행 권한·예시/실제/추정 비용을 혼동하지 않는지 확인한다. 통과해도 위 금융 계약·보안·경제성 시험을 대신하지 않는다.
